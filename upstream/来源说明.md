# 上游来源

本交接包的翻译插件基于 UU9i/Muck.Translater，保留作者标识。包内插件版本 **1.0.2** 为此次个人修订版本；上游 Thunderstore 下载包为 **1.0.1**，其插件内部版本为 **1.0.0**。`source` 为交接的修订源码，`UU9-README.md` 为原始说明。

- 插件原仓库：https://github.com/UU9i/Muck.Translater
- 插件包：https://thunderstore.io/package/download/UU9/Muck_Translater/1.0.1/
- 加载器包：https://thunderstore.io/package/download/BepInEx/BepInExPack_Muck/5.4.1101/
- BepInEx 5.4.11 源码：https://github.com/BepInEx/BepInEx/tree/v5.4.11
- UnityDoorstop 3.3.1.0 源码：https://github.com/NeighTools/UnityDoorstop/tree/v3.3.1.0
- Mono.Cecil：https://github.com/jbevain/cecil
- MonoMod：https://github.com/MonoMod/MonoMod
- HarmonyX：https://github.com/BepInEx/HarmonyX

加载器文件保持从原下载包提取的内容；保留 UnityDoorstop 3.3.1.0 的原始源码压缩包，BepInEx 5.4.11 源码使用上方官方链接，以及加载器/依赖的上游许可证文本。BepInEx 许可证取自 v5.4.11 标签；Doorstop 许可证取自 v3.3.1.0 标签；依赖许可证取自其上游仓库。第三方文件适用各自作者的条款。

游戏本体、游戏依赖程序集、玩家资料、存档、来源机器日志与微软字体未打包。构建依赖须来自接手机器自己的游戏安装。

存档和暂停基于 Michmcb/MuckMods 中的 MuckSaveGame 0.9.1（MIT），其保存功能沿自 flarfo 的 SaveUtility。修改版内部版本为 0.9.2，源码在 session-source/revision。

UU9i/Muck.Translater 上游仓库未附独立 LICENSE 文件；这里保留作者名与原说明，不将该部分标注为 MIT。各第三方组件仍适用其自身条款。
