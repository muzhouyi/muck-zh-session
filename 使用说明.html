Muck v1.5.1 安装与使用

适用于 Windows x64 Steam Muck 1.3 / Build 7077400。汉化插件 1.0.2，存档与联机插件 0.9.10。游戏本体需要自行通过 Steam 安装。

安装或更新

1. 房主和队友都正常退出游戏。

2. 下载 Muck-v1.5.1-install.zip，完整解压到普通文件夹，不能直接在压缩包里运行。

3. 双击 安装.cmd。已有本套补丁则自动更新，没有则安装；找不到游戏时，选择含 Muck.exe 的游戏目录。

4. 看到“安装完成”后，从 Steam 启动。双方使用同版本、重启游戏后重新建房。

找游戏目录：Steam 库 → 右键 Muck → 管理 → 浏览本地文件。安装会备份改动文件，保留现有存档、个人配置和无关模组。不要把旧模组备份留在 BepInEx/plugins 及其子目录中。

常用操作

按键功能
C开关导航菜单：资源、制作目标、宝箱与交易、家
H在当前位置新增一个家，最多8个
T开关队友名字、距离和方向提示
F7房主保存，等“存档完成”再退出
F8房主暂停或继续整局
F5 / F6刷新汉化 / 切换中英文

旧默认 N 键会迁移为 C。聊天输入时不触发这些快捷键；Esc 可关闭导航菜单。打开普通游戏菜单不等于联机暂停。

回家与找资源

H 按空位依次新增家1～家8；C → 家可更新位置或删除。旧单个家迁移为家1。每位玩家的家独立保存，房主 F7 保存成功后，继续同一存档会恢复；相同种子的新世界不会继承旧标记。

C → 资源，选择木材、矿石等；制作目标同时显示各项原料最近的一处；中间材料继续解析为基础原料。缺少现成目标时会提示。普通单资源选择只保留一种资源目标，家的路标不受影响。 红苹果、小麦只寻找地图上已存在的可拾取物；“蘑菇”统一寻找各类蘑菇。煤炭显示为“煤炭小块”“煤炭石矿”。

C → 宝箱与交易，可寻找免费、普通、稀有、传奇宝箱、交易 NPC 和交易营地。NPC 尚未出现时，先找交易营地，靠近后再找 NPC。已打开宝箱和已采集资源不再作为目标。

导航显示直线距离，需自行绕过地形。直接来源不存在时，部分材料会显示明确标注的“概率掉落”来源，这不代表必定获得材料。没有目标时会提示未找到。

食物和剑的数值提示

鼠标悬停食物时，分别显示血量、饱食度、体力恢复量；剑显示基础伤害。实际恢复受角色上限限制，实际攻击伤害受战斗规则影响。

在 设置 → 游戏玩法 → 物品数值提示 中开关。默认开启，切换立即生效，自动保存个人选择。关闭后仍保留物品原有名称和说明。

保存和继续

房主 F7 保存完成后退出。下次由原房主、原账号建房，原队友加入，在大厅点“读取存档”，选存档后开始。难度、模式和一天长度保持一致。

存档位于游戏目录 Saves；列表显示修改时间和存活天数，最近修改的排在前面。损坏文件会提示无法读取天数。

共用容器与死亡保留

普通箱子、熔炉默认可多人同时使用。左键取放整组，右键取半组或放一个，暂不支持 Shift 快速转移。房主确认每次操作；同格被队友或熔炉更新时，重新点击即可。

死亡默认保留背包、护甲和鼠标拿着的物品，死亡与复活规则照常。房主可在游戏关闭后编辑 BepInEx/config/MuckSaveGame.MichMcb.cfg，将 [Convenience] 下的 SharedContainers 或 KeepInventoryOnDeath 改为 false，重新开房生效。

恢复与常见问题

- 撤销安装：关闭游戏，双击“恢复.cmd”，选择游戏 .muck-zh-backups 中含 installation.json 的对应备份目录。恢复保留存档与无关模组；后来手动改过的文件会受到保护。

- 游戏版本不符或有冲突模组：安装会停止，先备份并处理重复 MuckSaveGame 或旧 SaveUtility。

- 中文方框：安装 Windows 中文语言字体后重试。

- F7/F8 等待队友：核对双方版本，重启并重新建房。

验证范围与限制

已完成本机隔离游戏检查与安装恢复检查；真实双机联机仍待验证。读档会刷新已采集的树木和矿石，部分野怪、掉落物和锅炉状态仍需联机核对。首次长时间游玩前，先用小进度测试保存、读取与暂停。
