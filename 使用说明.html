Muck v1.3 玩家使用说明

适用于 Windows x64 Steam Muck 1.3 / Build 7077400。本包提供汉化、保存继续、联机暂停、回家与材料导航、共用容器和死亡保留物品。下载或安装旧版本时，所有队友也必须使用相同版本。

第一次安装

1. 正常退出 Muck，把 ZIP 完整解压到普通文件夹，不能在压缩包内直接运行。

2. 双击 安装.cmd。它会自动寻找 Steam 中的 Muck；找不到时，选择含 Muck.exe 的游戏目录。

3. 看到“安装完成”后，从 Steam 启动游戏。

4. 房主和朋友都安装同一版本，再创建房间。

找游戏目录：Steam 库 → 右键 Muck → 管理 → 浏览本地文件。安装会备份修改文件，保留现有存档和无关模组，不需要 Agent、PowerShell 7 或手动编译。

已经装过：更新方法

同页下载 Muck-v1.3-update.zip，关闭游戏后，备份并替换 BepInEx/plugins/MuckSaveGame.dll 即可。备份不要留在 plugins 中。也可以用完整包重新运行“安装.cmd”，安装器会保留原存档和无关模组。

游戏里怎么用

按键用法
F5刷新中文词典
F6切换中英文
F7房主保存，等“存档完成”后再退出
F8房主暂停全局，再按继续
T开关队友名字、距离和方向提示，聊天输入时不触发
H标记当前位置为家
N打开资源与制作目标菜单

临时离开用 F8；需要关电脑或改天继续，先 F7，等聊天区出现“存档完成！”再退出。Esc 打开菜单不等于联机暂停。

回家与找材料

- H：标记当前位置为家，覆盖原来的家。画面提示方向、距离，地图上也有标记；N 菜单可以清除家。

- N：打开资源导航。在“资源”选木材或矿石；在“制作目标”选剑、弓、斧、镐，按游戏真实配方标记所需的木材和矿石。金属锭会对应到原矿。

- 每种材料标记最近的一处，采集后自动寻找下一处。距离是直线距离，需要自己绕过障碍；这不会传送角色。怪物掉落等非采集材料需另外获取。

- 每位玩家有自己的家。让房主按 F7 保存后，继续同一存档会恢复；相同种子的新世界不会继承旧路标。

多人共用箱子和熔炉

默认开启，所有玩家需更新到 v1.3。多人可以同时打开同一个箱子或熔炉。左键取放整组，右键取半组或放一个；共用容器暂不支持 Shift 快速转移。

两人抢同一格或熔炉刚更新产物时，房主先确认其中一次，另一人会看到“这一格已被更新”，重新点击即可。等待确认时暂时锁定物品操作，收到确认后恢复。

死亡保留物品

默认开启，保留背包、装备栏和鼠标拿着的物品。死亡仍然发生，复活与全队死亡规则照常。房主可在游戏关闭后编辑 BepInEx/config/MuckSaveGame.MichMcb.cfg，将 [Convenience] 下的 KeepInventoryOnDeath 或 SharedContainers 改为 false 关闭对应功能，重新开房生效。

下次怎么继续

由原房主、原账号重新建房 → 原队友加入 → 在大厅点“读取存档” → 选原存档 → 开始游戏。难度、模式和一天长度保持与上次一致。房主存档在游戏目录的 Saves 文件夹。

常见问题

- 安装窗口提示游戏运行：正常退出游戏，再安装；不要强行结束还未保存的对局。

- 未找到游戏：用 Steam“浏览本地文件”确认目录，选择含 Muck.exe 的文件夹。

- 提示版本不同、已有冲突模组：不要直接覆盖未知加载器；备份旧 SaveUtility 或重复 MuckSaveGame，停用冲突副本后再安装。

- 中文显示方框：给 Windows 安装中文语言字体，重启后再安装本包。

- F7 / F8 提示等待队友：确认双方已更新并重启、重新建房，等待几秒。最新版本优先使用 v1.3。

- 需要撤销完整安装：关闭游戏，双击“恢复.cmd”，选择游戏 .muck-zh-backups 中那次安装的备份子目录（含 installation.json）。恢复会保留 Saves 和无关模组；发现后来手动改过的文件会停止。

目前的限制

已通过单机游戏运行检查、容器并发规则与路标保存测试；尚未完成两台电脑的真实联机验证。遇到断线且容器仍等待确认时，不要继续移动物品，先核对房主与自己的物品状态。读档会刷新已采集的树木、矿石，锅炉和掉落物仍需联机核对。第一次正式使用前，用小进度核对暂停、保存和读档。MOD 并非游戏原生存档系统。
