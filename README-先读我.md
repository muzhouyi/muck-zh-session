# Muck 汉化与联机存档暂停包

这是给当前 Windows Steam Muck 1.3（Build 7077400）准备的个人修改版。包含汉化 1.0.2 和联机存档暂停模组 0.9.4。本项目公开发布版本为 v1.2；上游 MuckSaveGame 版本为 0.9.1，内部修订版本沿用 0.9.4。

## 怎么用

1. 所有人关闭游戏，安装同一个交接包，再重新创建 Steam 房间。
2. **T 键**开关自己这边的队友名字，默认开启。显示名字、距离和屏幕外方向箭头；名字保持原样，支持中文。聊天输入时按 T 不会切换。这个选择会记住，下次启动继续使用。
3. 房主按 **F8** 暂停整局；再按 **F8** 继续。暂停时大家可以打开菜单，怪物、物理和世界时间暂停。Steam 联机连接仍保持。
4. 房主按 **F7** 保存。也可以按 Esc，在菜单点击“存档”。等聊天区出现 **“存档完成！”** 后才能退出。房主的存档保存在游戏目录的 **Saves** 文件夹。
5. 下次由**原房主、原账号**创建房间。让原来的队友加入，在大厅点 **“读取存档”**，选择存档，再开始游戏。难度、模式和一天长度请选成上次的设置。
6. “设置 → 游戏”中的“每日自动存档”默认开启；每天开始保存一次。F5 刷新汉化，F6 切换中英文。

临时离开几分钟，使用 F8。需要关电脑或改天再玩，先 F7，等待成功提示，再退出。Esc 单独打开菜单仍遵循游戏原来的行为，联机真正暂停使用 F8。

## 安装

把整个文件夹解压到普通目录，让 Agent 先读《给Agent的交接说明.md》。它会找到 Steam 游戏目录、检查版本、保留其他模组、备份后安装。

安装入口为 `Install-MuckSession.ps1`，可传 `-GameDir` 指定游戏目录，或自动查找 Steam。`-DryRun` 只预览。

安装包同时包含汉化和所需 BepInEx 5。已安装 BepInEx 5 时保留加载器和全局设置。不要同时使用旧 SaveUtility，也不要在多个插件子目录重复放置 MuckSaveGame。已有这类模组时，由 Agent 先备份和协调，安装器会停止而不会静默覆盖冲突。

## 备份和恢复

每次成功存档先完整写入临时文件，再替换正式存档。上一次的好存档保存在相同文件名加 `.bak` 的文件中。写入失败或队友数据超时不会覆盖正式存档。

如果要恢复上一份存档，关闭游戏，先复制并保留当前 `.mucksave`，再把对应 `.mucksave.bak` 复制为 `.mucksave`。不用删除备份。

安装前的文件备份保存在游戏目录的 `.muck-zh-backups` 下，路径会在安装完成时给出。`Restore-MuckChinese.ps1 -BackupDir ...` 可恢复该次安装前的文件（此脚本名沿用基础汉化包，但覆盖本次包的所有改动）。它不会删除 `Saves` 或无关模组；发现安装后的手动修改会先停止。

## 能保存什么、有哪些限制

沿用 MuckSaveGame：玩家背包、装备、生命等状态、增益、世界天数时间、玩家建造物、容器物品、船与主要 Boss 等。对队友背包和增益恢复增加了就绪等待；存档必须收齐当前所有队友的五类数据，而且拒绝上一轮延迟到达的数据。

**它还不是游戏原生的完整存档系统。** 已砍的树、挖掉的矿石等采集资源在重新生成地图时会刷新；一般野怪不会全部恢复。上游还报告过掉落物和锅炉加工的联机问题，这次没有双机实测这些边界。贵重物品尽量放进背包或箱子再保存。不要依靠退出游戏自动保存。

0.9.4 修复“玩着玩着不能存档/暂停”：之前每次操作都重新查 Steam 房间成员标记，标记暂时消失就会拦截功能。新版用专门的 Steam P2P 通道 94 接收队友通信协议确认，同时把现有房间标记作为旧版本兼容的首次确认来源。确认和客户端编号、Steam 身份、当前玩家连接对象绑定；同一连接里不因临时房间信息消失而失效，退局、断开换人或重新连接后需要重新确认。

存档数据通信协议仍为 0.9.2，存档格式不变，已有存档可以继续读取。建议双方都更新到模组 0.9.4，才能通过新通道稳定确认。专用通道与原游戏和存档数据包分离，不会把自定义数据送到旧版游戏的数据包解析器。

这个包支持 Steam 房间联机。尚未确认队友时会限频提示；如果网络断开或收不到队友存档数据，仍会保留旧存档，并提示失败。旧式非 Steam 网络模式的多人功能不在此次支持范围内。

首次正式游玩前，建议两人用小进度验证一次：各拿不同物品并获得一个增益 → F8 确认双方暂停 → F7 等成功 → 原房主退出并重新建房读档 → 双方核对背包和增益 → F8 确认能继续。

## 已做验证

0.9.4 已针对本机游戏引用编译，50 项核心检查通过，包括连接确认缓存、换人/重连隔离、握手格式、屏幕边缘/背后位置计算，以及原有快照与原子写入保护。18 项安装/恢复检查在 PowerShell 7 和 Windows PowerShell 5.1 通过。

此前 0.9.3 已在实际临时世界检查保存、暂停、读档和标记发布。**0.9.4 的新增名字 UI 和新 P2P 确认还没有真实双机端到端验证。** 两边安装后重启，并按双人核对流程验证。

包内不含用户存档、账户信息或日志。测试源码不是正常安装插件。
